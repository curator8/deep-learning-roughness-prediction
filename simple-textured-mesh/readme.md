# Simple Textured Mesh

This is the Three.js viewer for the texture-prediction project.

It displays:

- the exported input albedo map
- the original roughness map from the dataset
- the predicted roughness map from the model

## Expected Input Files

The app reads these files from `static/predictions/`:

- `albedo_input.png`
- `roughness_original.png`
- `roughness_pred.png`

These are generated by:

```bash
cd ../texture-model-pipeline
python run_texture_model.py
```

## Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## UI

- `Predict`: loads and applies the predicted roughness map
- `Original`: shows the original dataset roughness map
- `New`: shows the predicted model output again
